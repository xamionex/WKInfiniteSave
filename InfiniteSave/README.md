# InfiniteSave

Makes disc saves in White Knuckle last forever.

Normally, every time you load (or get revived from) a disc save it uses up one of its lives, and once it runs out the save is deleted and your next death is a real game over.
With this mod installed, loading from a disc save never spends a use - you can revive from the same disc as many times as you want.

You still need to actually save to a disc the normal way (insert a disk, use the save terminal) - this mod only stops that save from ever being *used up* afterwards.

## Config

Found in `BepInEx/config/amione.InfiniteSave.cfg` after the first run (or in the in-game Mods menu if you have WKModMenu installed):

- **InfiniteDiscSaves** (default: `true`) - master on/off switch.

## Installation

- Install [BepInEx 5](https://github.com/BepInEx/BepInEx) for White Knuckle.
- Drop `InfiniteSave.dll` into `White Knuckle/BepInEx/plugins/InfiniteSave/`.
